# Agent Council Microsoft Store listing

Working copy for the first MSIX listing, in English and Korean. Use the existing reserved product **Agent Council**. Leave **What's new in this version** empty for the first submission.

## English (en-US)

### Description

Requires Windows 11 x64, Microsoft Edge WebView2, and at least one supported AI command-line tool installed separately and signed in on this PC. The selected providers may require internet access, an account or a paid plan. Agent Council displays live generative AI output from those tools.

Assign a lead agent to carry out your coding request and invite independent reviewers to check the result. Read each agent's work side by side and see how their findings inform a final report. You can also run a single agent or ask for review only.

Pick a local project and add reference folders. Follow each stage as it happens, then return to your conversation and drafts on the same PC. View provider account limits where available and see separately counted project tokens.

Compatible tools include Codex, Claude Code, Antigravity, Grok, Cursor Agent and Gemini CLI. Provider access and available features depend on the installed tool and its account. An optional browser companion can connect to your PC after approval on the desktop.

### Short description

Run separately installed AI coding tools together. Compare independent reviews, follow live progress and read a final report in one workspace.

### Product features

- Optional lead agent and independent reviewers
- Side-by-side results with live workflow progress
- Local project history, drafts and file previews
- Provider usage limits where available
- English and Korean interface

### Screenshot captions

1. Compare an independent review with the council's final report.
2. Choose a lead agent and independent reviewers for your next request.

## 한국어 (ko-KR)

### 설명

Windows 11 x64, Microsoft Edge WebView2, 그리고 PC에 별도로 설치하고 로그인한 지원 AI 명령줄 도구가 하나 이상 필요합니다. 선택한 제공사에 따라 인터넷 연결, 계정 또는 유료 요금제가 필요할 수 있습니다. Agent Council은 이 도구가 실시간으로 생성한 AI 응답을 표시합니다.

코딩을 맡을 담당 AI를 선택하고, 검수 AI에게 결과를 독립적으로 확인하도록 요청하세요. 각 에이전트의 결과를 나란히 읽고, 어떤 의견이 최종 보고서에 반영됐는지 살펴볼 수 있습니다. 에이전트 하나로 작업하거나 검수만 요청할 수도 있습니다.

PC의 프로젝트를 열고 참고 폴더를 추가하세요. 단계별 진행 상황을 확인하고, 같은 PC에서 이전 대화와 초안을 이어갈 수 있습니다. 제공사가 공개하는 계정 사용 한도와 프로젝트 토큰 사용량도 각각 확인할 수 있습니다.

Codex, Claude Code, Antigravity, Grok, Cursor Agent, Gemini CLI를 지원합니다. 제공사 접속과 기능은 설치된 도구 및 계정에 따라 달라집니다. 브라우저에서 PC에 연결하는 기능은 데스크톱에서 승인한 후 사용할 수 있습니다.

### 짧은 설명

별도로 설치한 AI 코딩 도구를 한곳에서 실행하세요. 실시간 진행 상황을 확인하고, 검수 의견을 비교해 최종 보고서까지 읽을 수 있습니다.

### 주요 기능

- 담당 AI와 독립 검수 AI 선택
- 나란히 보는 결과와 실시간 진행 상황
- 로컬 프로젝트 대화, 초안과 파일 미리보기
- 조회 가능한 제공사 계정 사용 한도
- 영어와 한국어 인터페이스

### 스크린샷 설명

1. 독립 검수 의견과 최종 보고서를 나란히 비교합니다.
2. 다음 요청에 참여할 담당 AI와 독립 검수 AI를 선택합니다.
